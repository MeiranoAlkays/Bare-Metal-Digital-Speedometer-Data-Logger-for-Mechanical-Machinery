# Bare-Metal-Digital-Speedometer-Data-Logger-for-Mechanical-Machinery
Membuat sistem pembaca kecepatan (RPM/Kmh) menggunakan sensor Hall Effect atau Optical Encoder. Tantangannya: Kamu dilarang menggunakan library Arduino.h standar untuk membaca sensor atau mengatur waktu. Kamu harus menulis kode menggunakan Interrupt dan Timer Register bawaan AVR/ESP32 secara langsung (bare-metal coding).
